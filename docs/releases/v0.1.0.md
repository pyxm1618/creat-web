# creat-web starter v0.1.0

`0.1.0` is the first internally versioned baseline of the reusable web-product starter. It is a starter-platform release, not a claim that any particular product deployment has completed production activation.

## Included baseline

- Configuration-first site, feature, product, SEO, route and legal surfaces.
- Better Auth account foundation with Google/Magic Link options, scanner-safe Magic Link confirmation, durable rate limiting and Turnstile verification.
- Optional Resend email, Waffo one-time/subscription/refund commerce, durable webhook inbox/retention, idempotent fulfillment and reconciliation.
- Credit grants/reservations/commit/release/expiry/reversal with cross-expiry reservation semantics and shared mutation serialization.
- Consent-gated GA4/Clarity integration with withdrawal and allowlisted analytics payloads.
- Strict script CSP/SRI build path, HSTS, browser isolation, sensitive-route cache/indexing controls and repository secret/supply-chain checks.
- Authenticated bounded internal jobs, health/readiness, redacted metrics/alerts and audited dead-letter inspection/retry.
- Database backup/restore verifier and CI restore drill, key-rotation/rollback runbooks, clean-checkout neutral-product proof and production-mode canonical browser checks.

## Upgrade impact

Owned products do not automatically inherit starter changes. Follow `docs/upgrade/owned-project-upgrades.md` and `CHANGELOG.md`; port platform/security changes intentionally and preserve product-owned configuration/content.

## Activation still requires real deployment facts

A product built from this baseline must separately provision and verify its real domain/Vercel project, database backup/PITR, legal operator/text, enabled provider accounts/credentials, alert receiver, search property and human-reviewed translations. Use `docs/releases/v0.1.0-staging-verification.md` as the activation checklist.

## Release evidence

The repository release gate requires unit/integration/contract/browser tests, migrations, architecture/security/SEO/i18n/commerce/subscription/credits checks, a 30-run credit race gate, synthetic isolated database restore, production-mode canonical/security browser output, performance budgets and independent clean-setup verification.
